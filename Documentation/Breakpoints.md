# Брейкпоинты

`Цель: понять, в каком режиме и в каком разрешении человек на сайте.`

### Описание

Quas поддерживает множество брекопинтов для `responsive-design`:

### Строгость

| Префикс | Размер     |
|---------|------------|
| `sm:`   | **640px**  |
| `md:`   | **768px**  |
| `lg:`   | **1024px** |
| `xl:`   | **1280px** |
| `2xl:`  | **1536px** |

Пример использования:
```html 
<div class="md:text-xl 2xl:text-2xl"></div>
```

### Ограничения

Так же доступно ограничение допустимой нормы вместо строгости:

| Префикс    | Размер              |
|------------|---------------------|
| `max-sm:`  | меньше < **640px**  |
| `max-md:`  | меньше < **768px**  |
| `max-lg:`  | меньше < **1024px** |
| `max-xl:`  | меньше < **1280px** |
| `max-2xl:` | меньше < **1536px** |

### Дополнения

| Префикс      | Фича                                    |
|--------------|-----------------------------------------|
| `landscape:` | Ширина больше высоты.                   |
| `portrait:`  | Портретный режим, высота больше ширины. |
| `print:`     | Сработает только при печати страницы.   |
