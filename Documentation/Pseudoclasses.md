### Описание

### Стейт взаимодействия
| Префикс    | Размер                   |
|------------|--------------------------|
| `hover:`   | **Курсор при наведении** |
| `visited:` | **Посещённая страница**  |
| `focus:`   | **Элемент в фокусе**     |
| `active:`  | **Активный элемент**     |
| `target:`  |                          |
